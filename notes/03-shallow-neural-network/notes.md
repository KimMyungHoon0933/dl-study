## 한문장 요약

얕은 신경망(shallow neural network)은 입력층($a^{[0]}=x$), 하나의 은닉층($a^{[1]}$), 출력층($a^{[2]}$)으로 구성하여 <BR>선형적인 분류만 가능한 로지스틱 회귀와 달리 비선형 곡선을 가진다. 


## 배우지 않은 사람 위한 설명

얕은 신경망은 입력층 → 하나의 은닉층 → 출력층으로 구성된다. <br>
은닉층과 출력층의 각 노드는 입력을 선형으로 결합하고 편향을 더한 뒤, 활성화 함수를 적용한다.

활성화 함수에는 sigmoid, tanh, ReLU, Leaky ReLU 등이 있다.
은닉층에는 ReLU 등의 비선형 활성화 함수를 사용하며, <br>
이진 분류의 출력층에는 sigmoid를 사용한다.

벡터화는 여러 노드와 여러 데이터에 대한 반복적인 계산을 행렬 연산으로 한꺼번에 처리하는 방법이다.
<br>


입력 데이터 X는 입력 특성이 n개인 데이터 하나는 열벡터이며, 데이터가 m개라면 각 열벡터를 수평으로 나란히 배치해 입력 행렬 X를 만든다 
<br>
정답 Y도 또한 각 데이터에 대응하도록 가로로 나열한다.


가중치 행렬 $W$ 의 차원은  현재 층의 노드 수 $\times$ 이전 층의 노드 수이다.
편향 b는 현재 층의 노드 수 만큼 존재한다.


Z와 A는 각 데이터의 계산 결과를 열로 나란히 배치한 행렬이다. 
따라서 행은 특정 노드의 결과를 각 열은 데이터에 대응된다. 




## 모르는 개념

tanh가 sigmoid를 스케일 조정하고 이동한 함수라는 설명을 명확하게 이해하지 못하여 추가적으로 공부하였다.

특히 sigmoid의 입력과 출력이 어떻게 변환되어 tanh의 수식으로 연결되는지를 중심으로 살펴보았다.

수식의 유도 과정을 확인한 결과, tanh는 sigmoid의 입력을 2배 하고, 그 출력에 2를 곱한 뒤 1을 빼는 방식으로 표현할 수 있음을 이해하였다.
