## 한문장 요약

얕은 신경망(shallow neural network)은 입력층($a^{[0]}=x$), 하나의 은닉층($a^{[1]}$), 출력층($a^{[2]}$)으로 구성되며, 선형적인 분류만 가능한 로지스틱 회귀와 달리 비선형 곡선을 가질 수 있게 된다.

## 배우지 않은 사람 위한 설명

얇은 신경망은 입력층($a^{[0]}=x$), 하나의 은닉층($a^{[1]}$), 출력층($a^{[2]}$)으로 구성되게 된다. <br>
이때 은닉층과 출력층의 노드에는 선형 변화과 활성화 함수를 가지게 된다. <br>

활성화 함수의 경우 sigmoid,tanh,relu, leaky relu를 주로 사용하게 된다. <br>
은닉층은 relu를 사용하며 이진 분류의 경우 sigmoid를 사용한다.<br>

이러한 얇은 신경망의 연산은 백터화를 기반으로 한번에 진행된다. <br>

입력 특성이 n개인 데이터 하나는 열벡터이며, 데이터가 m개라면 각 열벡터를 가로로 나란히 배치해 입력 행렬 X를 만든다 
<br>
이진 분류의 정답 Y도 각 데이터에 대응하도록 가로로 나열한다.

$$
{\Large X \in \mathbb{R}^{n \times m}, \qquad Y \in \mathbb{R}^{1 \times m}}
$$

가중치 행렬 $W$ 의 차원은  현재 층의 노드 수 X 이전 층의 노드 수이다.
편향 b는 현재 층의 노드 수 만큼 존재한다.

```math
{\Large
W^{[l]} \in \mathbb{R}^{n^{[l]} \times n^{[l-1]}},
\qquad
b^{[l]} \in \mathbb{R}^{n^{[l]} \times 1}
}
```

Z와 A는 각 데이터의 계산 결과를 열로 나란히 배치한 행렬이다. <br>
따라서 행은 특정 노드의 결과를 각 열은 데이터에 대응된다. 
이때 차원은 다음과 같다.

```math
{\Large
Z^{[l]}, A^{[l]} \in \mathbb{R}^{n^{[l]} \times m}
}
```
